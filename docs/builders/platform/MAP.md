**Layout (P3):** shared code is in `core/` (engine, game, verbs, books, transcript, codex, fx, music, art, intro, bot, market and their stylesheets); Spring's content is in `chapters/ch1/spring/` (story, scenes, cast, court, practice, standing, endings and their stylesheets). The root keeps the entry pages (`game.html`, `index.html`, `sound.html`), `version.js`, `manifest.webmanifest`, `icons/`, `tools/`, `tests/`, `docs/`. Core still contains Spring's constants and some Spring-only code (`core/engine.js` `R`, chapter functions in `core/game.js`): P5 and P6 move them out.
